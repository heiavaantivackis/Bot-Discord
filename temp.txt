Objet A : Le classement :
Il y a 2 types de classements :
- Classement de Gang ("Gang" est l'objet I)
- Classement de Joueur ("Joueur" est l'objet J)
Pour ces 2 types de classements il y a le classement général qui sera le résultat de plusieurs classements :
Les classements qui compose le classement général sont des modes de jeux, (comme duel, un joueur se bat contre un autre joueur par exemple) .
Le bot doit pouvoir créer un classement du type Gang ou Joueur lorsqu'on ajoute un nouveau mode de jeu*. 
En d'autre mots, il y a 1 classement par mode de jeu* , l'addition des scores dans tout les classements donnera le classement générale du même type. ("mode de jeu" est l'objet k)
Le scoring sera comme les Elo dans les echecs :

FORMULE :
\(\text{Nouveau\ Elo}=\text{Ancien\ Elo}+K\times (\text{Score\ réel}-\text{Score\ attendu})\)

EXEMPLE :
Le score réel : Vaut 1 pour une victoire, 0,5 pour un match nul et 0 pour une défaite.Le score attendu : C'est la probabilité de victoire calculée selon l'écart de points entre les deux joueurs (entre 0 et 1).Le facteur K (K-factor) : C'est un coefficient qui détermine l'importance de la partie. Il est plus élevé pour les jeunes ou les débutants (40) pour que leur classement s'ajuste vite, et plus faible pour les joueurs confirmés (10 ou 20) afin de stabiliser leur cote.

Pour le créateur de l'alerte et celui qui a été accepté cela leur renvoie le mode dans la quelle il vont jouer (si il y en a plusieurs cela va tirer au sort un mode de jeu).

Objet k : Les modes de jeux :
Les modes de jeux pour les gangs :
1. GLADIATEUR
Nombre de participants : À déterminer, avec le même nombre de participants dans chaque gang.
Principe : Chaque gang se place en file. Au début de l’épreuve, le premier participant de chaque gang entre dans
l’arène et s’affronte.
Lorsqu’un participant est KO, il est éliminé et doit quitter l’arène. Son gang doit alors envoyer immédiatement le
participant suivant.
Le participant encore debout continue donc le combat contre le nouveau joueur adverse.
Condition de victoire : Le gang qui élimine tous les participants du gang adverse remporte l’épreuve.
2. BATAILLE GÉNÉRALE
Nombre de participants : Libre, avec tous les joueurs disponibles de chaque gang.
Principe : Les deux gangs envoient tous leurs participants en même temps dans la zone de combat.
Avant l’épreuve, une méthode d’élimination doit être choisie :
• KO : un joueur mis KO est immédiatement éliminé.
• KO + finisher : un joueur mis KO doit être achevé pour être définitivement éliminé.
La méthode choisie doit être la même pour les deux gangs.
Condition de victoire : Le gang qui possède encore des joueurs en jeu lorsque tous les joueurs adverses sont
éliminés remporte l’épreuve.
3. DUEL DE STYLE
Nombre de participants : 1 combattant de chaque gang.
Principe : Chaque gang désigne un combattant possédant le même style de combat que son adversaire.
Condition de victoire : Le combattant qui met son adversaire KO remporte le duel.
4. DUEL NO ULT
Nombre de participants : 1 combattant de chaque gang.
Principe : Le style de combat est libre, mais l’utilisation des ultimes est interdite.
Condition de victoire : Le combattant qui met son adversaire KO remporte le duel.
5. DUEL NORMAL
Nombre de participants : 1 combattant de chaque gang.
Principe : Les deux participants s’affrontent librement, sans restriction particulière.
Condition de victoire : Le combattant qui met son adversaire KO remporte le duel.
6. BATTLE ROYALE
Nombre de participants : À déterminer selon le format choisi.
Formats possibles :
• Solo : chaque joueur combat individuellement.
• Duo : 2 joueurs par gang.
• Trio : 3 joueurs par gang.
• Squad : 4 joueurs par gang.
Principe : Les participants sont envoyés dans le lycée et s’affrontent selon le format choisi. En équipe, les joueurs
d’un même gang combattent ensemble.
Un joueur mis KO est éliminé.
Condition de victoire : La dernière équipe encore en jeu remporte le Battle Royale.
7. SUMO
Lieu : Le cercle blanc situé sur le toit.
Nombre de participants : 1 combattant de chaque gang.
Principe : Les deux participants commencent dans le cercle. Le but est de faire sortir son adversaire du cercle ou de
le mettre KO.
Si un participant sort lui-même du cercle, il est éliminé.
Condition de victoire : Mettre son adversaire KO ou le faire sortir du cercle.
Une fois le combattant éliminé, il ne peut pas être remplacé.
Condition de victoire : Le gang dont le combattant réalise le plus de KO remporte l’épreuve.
9. DOMINATION
Nombre de participants : À déterminer, avec le même nombre de joueurs pour chaque gang.
But : Un endroit est défini comme zone à conquérir.
Principe : Les deux gangs doivent tenter de prendre le contrôle du territoire adverse.
Être mis KO ou achevé n’est pas éliminatoire.
Condition de victoire : Un gang doit rester 10 secondes dans la zone dédiée sans être interrompu pour conquérir le
territoire adverse
